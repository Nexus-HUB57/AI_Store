## How the mass generation works

The 1200+ MCPs were generated by:

```
baitcoin/mcp/scripts/generate_mass_portfolio.py
  │
  ├─ Wave 3:  30 domains × 25 patterns → 750 server.py + manifest.json
  ├─ Wave 4:  10 providers × 25 patterns → 250
  ├─ Wave 5:  4 tiers × 25 patterns → 100
  └─ Wave 6:  4 regions × 25 patterns → 100
baitcoin/mcp/scripts/build_all_manifests.py
  └─ Recursive scan → 1228 .aipkg archives + 2.2 MB portfolio.json
```

Each generated MCP has:

- 3-5 tools (CRUD + search + stats + validation pattern)
- Complete `.aipkg`-compatible manifest with `tools[]` array
- Standard tags + icon
